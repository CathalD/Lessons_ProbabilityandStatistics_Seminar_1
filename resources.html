R and course resources

The same practical workflow across two university seminars: ask, model, observe, predict and evaluate.

The course method

We will teach probability and statistics as tools for answering empirical questions. Each activity starts with a scientific problem, introduces a small set of concepts and assumptions, derives a theoretical prediction where possible, and then asks students to construct an empirical model. Students commit to predictions and evaluate them using observations excluded from model construction.

Lesson 1 develops this workflow for independent observations. Lesson 2 asks how information about one outcome changes predictions for another. Dice and cups provide controlled experiments; the final assessment in each seminar uses ecology and soil measurements. This plan covers the course structure, revisions to the existing Lesson 1 website, the full Lesson 2 sequence, assessment questions and marking guides, an R pathway, and an implementation order.

The models we will distinguish

ModelWhat it providesWhat we must state
TheoreticalProbabilities implied by a proposed mechanism or model family.Assumptions, known quantities and unknown parameters.
EmpiricalEstimated probabilities or relationships constructed from training observations.Data, estimator, sample size and sampling design.
ObservationA link between the process and the instrument readings.Measurement error assumptions or calibration information.

A theoretical model is a conditional account of a system. Agreement with a small sample supports its usefulness for a stated task; it does not establish that the model is true. In a field dataset, the theoretical tools may specify how to estimate and predict without supplying a known true probability curve.

The common practical sequence

Question → variables and assumptions → theory and tools → experiment → empirical model → comparison → locked prediction → new observations → evaluation and revision.

We will protect a 25-minute transfer assessment in each seminar. Routine data collection can be pooled across groups. Long derivations, repeated simulations and R setup belong in preparation or follow-up work so that students retain time to draw, calculate and explain.

Introduce the concept before asking students to use it

Each activity opens with a 60–120 word explanation, one annotated visual, definitions of the symbols, one worked calculation, and one directly relevant source link. The source appears beside the explanation. The student reads the short explanation in class; the linked chapter or paper is further reading. A concept check must be answered before the experiment opens.

Keep the target and notation visible

Use S for a true dice total, Y for its fuzzy reading, and S* for a new hidden true outcome. Subscripts A and B identify cups; i identifies a location or trial when defined. N is the controller result in the random-sum experiment. Use P for an event probability, p for discrete mass, F for a CDF and f for continuous density. A hat identifies an estimate. [R1]

The additive equation is a candidate observation model. Independence, zero mean and constant error variance are separate assumptions. A blurred cup may produce guessing, clipping or bias. Retain the clear reference separately and reveal it after the original forecast is locked. Comparing an empirical distribution of Y with a theoretical distribution of S requires an explicit measurement assumption. [R15]

Student drawing and function fields begin blank. An optional computed empirical plot becomes available after the student has made a first attempt. A theoretical curve may be introduced before observation; the software must label its assumptions and distinguish it from an estimated curve.

A first learner example

x <- c(0, 1, 7, 2, 3, 1, 2, 1)
prop.table(table(x))
Fhat <- ecdf(x)
plot(Fhat, xlab = "Insect count", ylab = "Cumulative proportion")
q <- mean(x <= 2)
expected_count <- 4 * q

The interpreter computes a result; the learner must still name its population and assumptions. Retain units in plot labels. Use the exact inequality from the scientific question. For continuous measurements, do not replace an interval probability with a fitted density height.

Further practice

Extensions after the core seminar

  • Use the original controller N = 1–6. The mean total is 49/4 = 12.25 and its variance is 735/16 = 45.9375. Compare with the core N = 1–3 mean of 7 and variance of 14.
  • Study the average M = S/N. Its conditional mean remains 3.5 while its conditional variance is 35/(12N). This provides dependent variables with zero covariance and a visual introduction to changing variance.
  • Run keep-or-refresh time sequences. With a one-half retention probability and a stationary initial fair draw, the lag-h correlation is (1/2)^h. A zero-retention control provides independent observations.
  • Run continuing migration histories and compare them with reset replicates. Track composition as the state; noisy totals alone need not identify that state.
  • Fit a semivariogram to field residuals using gstat, inspect trend and anisotropy, and compare candidate covariance models using validation that matches the intended application. Refit model choices inside training folds.
  • Use a Gaussian driving process in place of dice to construct a genuinely Gaussian spatial model. Compare its joint distribution with the discrete overlapping-dice process.

Prepare the physical seminar

Groups of three or four need labelled regular dice, four low/high irregular dice for the exchange exercise, controller labels, cups, a tray, graph paper and a shared-contribution board. Seven values for a spatial world can be generated by rolling one die seven times and recording the results on cards. A recorder preserves trial order and links; an observer estimates fuzzy totals; a checker retains clear reference values. Rotate roles, and retain observer identifiers when investigating measurement effects.

Pilot the cup visibility and the time needed for a complete trial. Standardize viewing time, lighting and handling. Moving fixed face values requires careful transfer without shaking. An independent replicate must be reset as specified; a continuing history must preserve its state.

Prepare the data and assessment

The worked R script supplies reproducible splits, real observations and answer calculations. Student handouts receive only training data and target predictors. Keep validation outcomes separate until prediction submission. Real field measurements do not come with a known latent truth, and a toy mechanism cannot establish how a particular ecological system works.

Use the final assessment responses to choose the next topic. Frequent errors about conditional denominators call for another paired-data task; errors about covariance call for more mechanism comparisons; errors about uncertainty call for repeated prediction checks before a longer treatment of Gaussian processes.
